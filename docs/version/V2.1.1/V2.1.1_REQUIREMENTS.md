## DEV-01 交付要求

- 正式名称仍为 **Workday Escape**，现有 appId、executableName、用户数据目录保持不变。
- 使用用户确认的 `D:\Workday-Escape-Assets\v2.1.1\Workday-Escape-v2.1.1-icon-assets\` 中的同名 PNG / ICO；用户已明确更正素材路径。PNG 为原始参考，ICO 原样复制至 `desktop/packaging/Workday-Escape-icon-approved.ico`，以 `win.icon` 接入构建。不得替换、重绘或修改原素材。
- 版本及 package / lock 根元数据为 **2.1.1**；Windows x64 Portable 单文件名为 **Workday Escape.exe**，由 `portable.artifactName` 直接生成。
- ZIP 名为 **Workday-Escape-v2.1.1-Portable.zip**，根目录仅有 **Workday Escape.exe**；不带目录、staging、日志、配置或额外运行环境。
- 使用独立新输出目录，保护 V2.0.0 / V2.1.0 EXE、Tag、文档、配置与备份。沿用 afterPack 和完整静态检查，仅适配检查器版本、文件名及报告标签。

## 验收与发布边界

自动验证限于 Typecheck、构建、ICO 解码与静态预览、外层 / 内层 PE 图标与版本、7-Zip 解包、原有完整性 / 安全 / 资源 / 架构 / 权限 / 体积检查、ZIP 完整性与解压后哈希、历史交付保护。具体结果和文件身份见 [TASKS](V2.1.1_TASKS.md)。

Windows 资源管理器、主窗口 / 任务栏实际图标，以及 ZIP 解压后启动和基本运行，均待用户人工验收；静态结果不能替代 GUI 体验。窗口沿用 Electron 的 Windows 默认行为，使用可执行文件内嵌图标，无需修改窗口源码；既有猫鱼托盘图标不变。

未签名 / SmartScreen 限制、历史未验原生异常及 QA-01 两项 CIM 权限失败继续保留；内置日历仍仅核验 2024～2026。不得关闭系统防护，不将个人验收扩为完整对外分发 PASS。

本任务只授权 DEV-01 实现、构建、静态核验、文档、Commit 和普通 Push；不合并 main，不创建 `v2.1.1` Tag、GitHub Release，不上传 EXE / ZIP。完成后停止，待用户实际确认并另行授权发布。
