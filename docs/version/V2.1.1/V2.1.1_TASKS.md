### 复现与修复

用 DEV-01 原始 ASAR、Electron 44.7.0、临时配置和不可见窗口复现。英文、空格和中文对照路径可以读草稿。路径分别含 `~`、`[` / `]` 时，两次调用都命中已登记且存活的窗口，`senderFrame` 与主 Frame 相同，只有 URL 字符串比较失败。两条 URL 解码后指向同一路径。诊断只记录路径类别、布尔条件和结果码。

旧代码用 `pathToFileURL()` 生成登记 URL，而 Electron `loadFile()` 使用旧式 `url.format()` 生成实际加载 URL，导致同一文件在部分合法路径下的 URL 表示不同。`desktop/src/main/index.ts` 改为由 `loadURL()` 使用同一个已登记的可信 URL 加载 Main 和 Mini。IPC 继续执行已登记窗口、当前主 Frame、精确 URL 及角色能力检查，Preload 和安全选项沿用原实现。此为已复现的代码缺陷，同事设备上的修复效果须以实测确认。[Electron 44.7.0 的 loadFile 实现](https://github.com/electron/electron/blob/v44.7.0/lib/browser/api/web-contents.ts)
