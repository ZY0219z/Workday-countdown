## DEV-01 主界面加班快捷开关

倒计时容器左上角新增加班开关。开启前选择结束时间，点击月亮修改当前班次时间，关闭时二次确认。取消保存成功后提示「今天不加班，回去好好休息～」。

开关读取当前班次快照的加班分钟数。快捷操作与设置页共用设置控制器，复用 `settingsDraft.setExpectedEnd`、`config.save`、修订检查及 Main 的跨日校验。正式保存后按配置修订号刷新快照。写入失败时撤回本次独占的临时草稿，时间输入保留在弹窗中供重试。写入响应不明确时先核对 Main 的修订与保存状态。
