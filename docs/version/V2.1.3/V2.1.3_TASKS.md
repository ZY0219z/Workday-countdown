## DEV-01 主界面加班快捷开关

倒计时容器左上角新增加班开关。开启前选择结束时间，点击月亮修改当前班次时间，关闭时二次确认。取消保存成功后提示「今天不加班，回去好好休息～」。

开关读取当前班次快照的加班分钟数。快捷操作与设置页共用设置控制器，复用 `settingsDraft.setExpectedEnd`、`config.save`、修订检查及 Main 的跨日校验。正式保存后按配置修订号刷新快照。写入失败时撤回本次独占的临时草稿，时间输入保留在弹窗中供重试。写入响应不明确时先核对 Main 的修订与保存状态。

## DEV-03 主窗口启动位置与设置页布局

基线 `544071309f73`。解决主窗口冷启动靠工作区左上、精简后设置卡片下方留白过多的问题。

- `index.ts`、`window-bounds.ts` 在创建主窗口时读取主屏 `workArea`，校验并沿用可用的保存尺寸，再重新计算居中坐标。窗口加载页面前复用原生边界修正，处理高 DPI 下的边框取整。运行时显示恢复和显示器变化继续使用原有路径。
- `App.vue` 为设置页的 `main` 单独使用纵向 Flex。空间充足时卡片通过自动块向边距居中，空间不足时从顶部排列并随页面滚动。

`npm run build`（含 TypeScript 检查）、`npm run test:lifecycle`（53/53）和后台 Electron `playwright test --grep 'V2.1.3 DEV-03'` 均通过。单元用例覆盖非零工作区坐标、负坐标、多显示器选择、保存尺寸和 100% 至 200% 模拟 DPI。后台用例对照设置页 Header、宽度和表单内部布局，验证小窗口可滚动到保存按钮，并核对切回主页后的布局与启动时一致。
