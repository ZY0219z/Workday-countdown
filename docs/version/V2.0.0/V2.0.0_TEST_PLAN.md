## 测试分层与取证

1. domain 单元测试：固定 clock/policies/calendar 输入，无 Electron/网络/真实当前日期，检查数学结果、状态、来源和错误；有必要的日期/区间不变量测试，避免仅复制实现。
2. main 服务测试：一次性用户目录、故障注入、写入队列/revision/备份；原源文件摘要前后对照。测试不得覆盖真实配置。
3. Windows Electron 集成：真实 Preload、IPC、两个窗口、tray、单实例和退出；既有 POC 安全与退出覆盖保留，应用不能在测试里关闭 sandbox。
4. UI 验收：固定时间截图，亮/深、不同窗宽/DPI、各种业务状态、键盘与减弱动画。
5. 真实 portable 验收：仅复制同一 EXE 到无开发环境的 Windows 标准用户机器，人工打开、断网、保存、重开、退出；记录 EXE SHA-256、OS build、硬件、账号权限和签名状态。

自动化只能使用本地测试 profile/调试参数；正式 EXE 正常启动不额外开放调试端口。退出检查包括 launcher、main、renderer、GPU/utility 进程及本次临时目录，不能只看页面消失。

### G05 已确认性能基线与测量口径

参考机：Win11 x64、至少4逻辑核、8GiB RAM、SSD、标准用户，记录型号/电源模式/显示缩放/scaleFactor；Win10条件验收用同口径。预算包括所有main/renderer/GPU/utility/launcher（包括隐藏且驻留的主窗），不能只测一个renderer。D01未做资源实测，未发现需改数值或不可测的指标；实现前若发现问题须报告。

- CPU百分比 = 所有进程CPU秒增量 /（墙钟秒增量 × 逻辑核数）×100，全机归一；预热30秒、连续120秒、建议1秒采样，记录PID/起止时间以避免漏计或重复计数。平均可见主窗/mini≤2%，tray-only≤0.5%，报告均值/P95，不混用单核口径。
- 总Private Working Set：单一可见视图≤250 MiB、tray-only≤200 MiB；必须计入隐藏草稿窗。原双窗可见≤350 MiB保留为历史条件预算，但Q08首发互斥、该场景不适用，不能据此放宽首发250 MiB或增设共存功能。8小时每小时采样，末稳定小时相对首稳定小时增长≤20%，无持续泄漏趋势；100次切窗不积累renderer/订阅。
- 内存测量用按PID的Private Working Set（如Windows `WorkingSetPrivate`），不替换为Private Bytes/虚拟内存。D01只读确认本机计数器元数据有IDProcess/WorkingSetPrivate，不等于性能实测通过；目标机仍须确认采样工具。小时窗口多点采样并保存曲线，不能用偶然单点涨跌宣称有/无泄漏。
- 冷启动（进程不在运行，从SSD双击到可操作主窗）≤10秒；同实例恢复/切到主窗≤1秒；mini恢复≤1秒。分别测正常网络和真实断网，不预先解压为“冷启动”。
- 电源模式（交流/电池供电）与开关动画差异记录，不要求为性能测量强制断电；隐藏/午休也暂停动画。正式EXE≤120 MiB基线不变；不能用外置资源规避单文件要求。
