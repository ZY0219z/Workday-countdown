# D04 年度工作日历逐项核验记录

核验日期：2026-10-13。范围仅为国务院办公厅2024–2026年度通知明确列出的休假/补班日期；普通周末依周规则判断，不等于通知特别安排，不将建议休息、地方假期或实际出勤混入。数据在`desktop/resources/calendar/`，本轮不修改Python集合、用户配置或联网更新程序。

## 核验方法和可追溯性

1. 本轮实际读取政府转载全文并交叉查看中国政府网检索结果，核对通知标题、文号、发布日和每个日期区间。中国政府网2024/2025原页面直接open返回403，不能记录为已成功打开；可靠全文采用下列政府转载。
2. 仅展开通知明确日期区间，不把“与周末连休”所接普通周末追加为特别休假日期。2024-02-09为鼓励单位安排休息，不入restDates。
3. 与本地`workday_counter.py:41`的HOLIDAYS及`:75`的WORK_WEEKENDS逐项集合比较，不运行Tkinter或改源。新数据按通知独立生成，不用Python集合反证官方准确性。
4. 使用D02安全结构与D03真实日期校验；检查年份、升序唯一、休假/补班互斥、来源/核验元数据、计数和SHA-256。离线测试另用已审查通知区间fixture逐日展开对照。
5. 下列SHA是`ordered-fields-v1`规范化业务内容的UTF-8 SHA-256，不是网页摘要或文件字节SHA。manifest固定对应年度/版本/摘要；核验身份只能来自受审查内置摘要白名单，普通输入自称verified、单独计算出SHA或有政府域名均不能自动证明官方准确。
