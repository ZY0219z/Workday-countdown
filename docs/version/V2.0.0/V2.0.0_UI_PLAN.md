## 主仪表盘 F01

主视觉顺序：下班剩余时间 → 当前工作状态 → 小鱼进度 → 休息/发薪 → 在职统计 → 设置/窗口入口。保留“摸鱼”特色，避免把元数据、长说明或装饰放在大数字之前。

建议默认 720×780 DIP，最小内容目标 480×560 DIP；创建时限制到当前显示器 workArea，若系统缩放导致可用高度小于该目标，应降低窗口最小高度并允许内容纵向滚动。宽度 ≥640 使用两列辅助卡，<640 为单列。首发原生 Windows 标题栏，保留系统移动、缩放、关闭和任务栏操作。

```text
┌──────────────────────────────────────────────┐
│ Workday Escape        日期/星期    迷你窗 设置 │
├──────────────────────────────────────────────┤
│ 工作中 / 午休 / 加班中                         │
│              03:26:18                        │
│ 距离下班  ·  08:30–18:00  ·  今日加班 30 分钟  │
├──────────────────────────────────────────────┤
│ 今日工作进度    [ 水面 ─── 小鱼 ─── ]  62%    │
│ 午休不计入进度 / 已调整班次（必要时）          │
├───────────────────────┬──────────────────────┤
│ 下个休息日     2 天    │ 下个发薪日    8 天   │
│ 日期/星期与覆盖来源    │ 日期/调整原因        │
├───────────────────────┼──────────────────────┤
│ 在职自然日    453 天   │ 累计计划工作日       │
│ 入职日期              │ 日历推算/不完整标识  │
├──────────────────────────────────────────────┤
│ 日历缺失、配置恢复等必要提示（可展开处理）    │
└──────────────────────────────────────────────┘
```

数字为示意，非当前业务实算；两项统计按Q01不含今天，入职日0。累计计划工作日始终注明“按当前工作制推算”，不能称实际出勤；缺年另有估算/不完整标记。两列阅读保持DOM顺序，只有一个内容滚动区；标题/操作可见，长数字换行而不缩到不可读。

| 组件 | 显示与操作 |
| --- | --- |
| `CountdownCard` | 状态、HH:MM:SS、最终结束日期时间、班次及加班摘要；跨夜必须显示结束日，不只显示时分 |
| `FishProgress` | 数字百分比与鱼同时表达进度；休息或数据不完整时有明确文字，不用 0% 掩盖不可计算 |
| `MetricCard`（休息日） | 今天休息/天数/无近期休息日；日期、星期、官方/自定义/周规则的简短来源 |
| `MetricCard`（发薪） | 今天发薪/天数/无法计算；基础日期和调整原因在次级行，不表示已经到账 |
| `MetricCard`（在职） | 已过自然日与累计计划工作日独立，范围不含今日；未来入职日两项0并提示尚未入职；未设置有入口 |
| `StatusBadge` | 工作/午休/加班/休息及估算均有文字和颜色；估算标记贴近受影响值，不能只放可折叠页脚 |

### 状态展示

| 业务状态 | 主标题 / 数字 | 进度和下一步 |
| --- | --- | --- |
| rest | “今天休息”取代倒计时数字 | 显示下次工作日期/无进度；不提供独立休息日临时班次 |
| beforeWork | “距离上班”，目标为班次开始 | 有有效待开始排班时进度0，鱼在起点；不是无班次假0 |
| working | “距离下班”，秒级大数字 | 鱼按当前净工作进度移动 |
| break | “午休中”，仍可查看最终下班倒计时 | 进度冻结，微动画暂停；午休结束时间次级展示 |
| overtime | “加班中”，突出最终结束日期时间 | 同一净进度包含加班时长，不增加双轨，不显示旧的已经下班状态 |
| finished | “已经下班啦！”/“加班结束啦！” | 100%，微动画停止；显示下一班信息 |
| incomplete | “需要检查设置/日历” | 不可计算项显示“—”，提供具体处理入口；可独立计算项继续显示 |

状态组合全部来自同一个 snapshot；跨夜期间以进行中班次为准。屏幕阅读器只播报状态变化和保存结果，倒计时为 `role=timer`，不每秒 aria-live 播报。

缺官方年度数据时，周规则回退参与的休息日、发薪日、班次/进度/倒计时各自显示“估算 · 年度数据不完整”，附涉及年份和来源；明确日期覆盖显示自定义。自然日不加日历估算标记。已加载但未核验的来源不能显示官方已核验；日历缺失不阻止启动和其他可确定结果。

## 小鱼动画 F05

- 轨道高度建议 44 DIP，鱼 28–32 DIP。保留旧资源，后续优先复用/评审简化 SVG 或现有鱼图片；本阶段不生成或替换资产。
- 横向位置 `x = p × max(0, trackWidth − fishWidth)`，p 为快照中夹紧的 0–1 进度；位置通过一个 transform 更新，避免鱼在 0%/100% 时越界。ResizeObserver 只在尺寸变化时重算边界。
- 进度平滑过渡建议 200–300ms，轻微游动约 3 秒周期，只动 transform；不用 JS 每 40/50ms 重绘 Canvas，不引入常驻粒子、随机数循环或重复 requestAnimationFrame。
- 工作状态且窗口可见才播放微动画。午休、结束、隐藏、最小化、系统减少动画或用户低动画模式时暂停；数据重新计算仍能直接正确定位。
- 若修改加班造成进度回退，显示“班次已调整”，动画追随新进度，不能给出虚假的旧百分比。
- CPU 是否低由 G05 实测；若超预算，先关闭微动画/采用静态鱼，不放宽采样口径或伪称 CSS 动画无需资源。

## 迷你悬浮窗 F06

建议280×132 DIP，最小内容目标240×112，仅显示状态、倒计时、简化进度和恢复入口。按Q08默认不开启，用户主动开启后与主窗互斥；置顶只由手动开关，不因开启而强制置顶。不实现共存模式。

```text
┌────────────────────────────┐
│ ≋ 拖动区  工作中    置顶  × │
│         03:26:18           │
│ [───── 小鱼 ─────]    62%   │
│                  打开主窗口│
└────────────────────────────┘
```

拖动区用Electron app-region，按钮必须no-drag；置顶状态可读，×表示隐藏。提供明确“打开主窗”按钮，首发不额外依赖未审查的拖动区双击交互。不吞掉按钮/键盘焦点，不启用点击穿透。

托盘可恢复隐藏的迷你窗；切换先隐藏当前窗再显示目标窗，始终最多一窗可见。首次启动主窗，此后记住位置，位置恢复不自动启用迷你或双窗。主窗设置草稿切换前已同步并保留，恢复主窗后继续编辑。DPI/副屏变化把位置限制到workArea；迷你窗显示跨日期目标和估算来源。

## 托盘和关闭 F07/F12

- Windows 原生 tray 图标打包内置，适配常见尺寸；托盘右键菜单建议：即时状态与剩余时间（不可点击）→ 打开主窗口 → 显示/隐藏迷你窗 → 设置 → 分隔 → 退出。
- 左键打开/聚焦主窗，双击幂等执行同一恢复动作；若mini可见先隐藏mini。不将普通鼠标动作绑定数据清除。
- tooltip 简短：`Workday Escape · 工作中 · 约 3小时26分`；右键展开时重算精确值。不能依赖 tooltip 实现每秒更新需求。
- 主窗×默认隐藏到托盘，首次明确说明；设置可改关闭即退出。最小化保留任务栏，是独立状态；mini×只是隐藏。托盘“退出”真正结束进程，若有未保存草稿先执行Q12三选确认。
- 托盘不可用或被创建失败时不允许静默隐藏全部窗口，须保持主窗恢复入口或提示并退出。测试覆盖系统隐藏图标区域/Explorer 重启。

## 设置中心 F08

采用主窗口内 `SettingsView`，返回仪表盘不新开 renderer；≥720 DIP 可用左侧分组导航，窄窗改顶部选择器。每页表单独立布局，底部统一“保存”“取消/返回”，有未保存草稿标识。

| 分组 | 字段与校验反馈 |
| --- | --- |
| 时间与日程 | 入职日期、每周工作日、开始/结束时间、显式跨夜、可选午休；日期/正净时长/休息重叠等错误贴近字段 |
| 发薪 | 每月几号、短月和非工作日策略；展示下一次计算预览，说明只是计划日期 |
| 加班 | 所属班次日期、0–600分钟、最终结束日期时间；历史设置保留，清除明确指出目标日期，其他历史不变；不创建休息日临时班次 |
| 工作日历 | 覆盖年份、来源/版本、核验状态，自定义work/rest覆盖及撤销；无日期级自定义班次时间；缺年醒目说明估算影响 |
| 外观 | 系统/亮/深、少量配色、减弱动画；预览可即时但取消须恢复保存值 |
| 窗口与托盘 | 隐藏到托盘/关闭即退出、迷你开启、手动置顶、位置恢复；无共存/上次可见模式自动启动/开机启动功能 |
| 数据 | Python/POC 配置导入、正式配置导入导出、备份恢复；显示影响字段，不把内部 schema 术语当主流程 |

保存时禁用重复提交，成功后两窗/托盘同时更新；保存失败保留草稿和当前已应用值，显示写入权限/文件占用的具体可处理提示。跨窗修改发生 revision 冲突时先重新加载并预览差异，不静默覆盖。

切到mini或关闭隐藏到tray不等于离开设置，保留草稿；返回仪表盘/离开设置及真正退出则有dirty时提示“保存 / 放弃 / 继续编辑”。继续编辑取消离开/退出；保存失败也保持草稿、旧值和可操作页面，不提示成功。明确放弃才丢弃草稿。取消预览恢复保存的主题值；不能为隐藏/省内存销毁dirty表单。

## 数据/日历导入和恢复 F10/F11

导入流程：选择文件 → 只读校验 → 当前/导入值对照 → 字段选取与旧加班日期确认 → 提示将备份现有配置 → 确认应用 → 结果。用户能取消每一步，取消不创建正式配置或迁移完成标记。

无日期旧加班显示“无法判断所属班次”，默认跳过；只有用户单独选择有效班次日期并确认后才可应用，不把文件时间或今天当归属。Python/POC并存按来源选字段，不自动合并覆盖。成功前校验/备份/安全保存；错误可理解、不泄露堆栈。

配置损坏时显示“已从最近有效备份恢复”或“未找到有效配置”，保留损坏源并提供只读导出/重新设置入口；不把恢复失败当成新用户而静默写默认。年度日历缺失提示覆盖年份与离线导入入口，核心应用仍可打开。

## 视觉规范 F09

已实施 CSS tokens，所有窗和设置复用，不每组件硬写独立颜色。下表为海蓝基准，珊瑚背景/卡片差异见末节四配色表。

| token | 亮色 | 深色 |
| --- | --- | --- |
| background | `#F0F7FD` | `#172331` |
| surface | `#FFFFFF` | `#213043` |
| text | `#24374B` | `#F1F5F9` |
| mutedText | `#506178` | `#CBD5E1` |
| border（海蓝卡片） | `#BECDDD` | `#586E86` |
| controlBorder | `#6B819C` | `#98ABC3` |
| accentText（海蓝） | `#2563EB` | `#60A5FA` |
| accentText（珊瑚） | `#BE123C` | `#FDA4AF` |
| primaryButton（海蓝/珊瑚） | `#2563EB` / `#BE123C`，白字 | 同亮色按钮背景，白字 |
| successText | `#166534` | `#86EFAC` |
| warningText / errorText | `#9A3412` / `#B91C1C` | `#FDBA74` / `#FCA5A5` |

四配色普通文本/次文字/品牌字和语义状态实测均≥4.5:1；大号文本仍以≥3:1为门槛，不能因数值是主色免测。主题配色只影响品牌/未来进度，不改变警告/错误语义。系统高对比度已有Canvas等系统色、边界和焦点基础样式，Headless强制色模拟通过，不代表Windows实机验收；阴影不是唯一边框。

字号：倒计时 44–56 DIP（窄窗降到 36），指标值 26–32，标题 18–22，正文 14–16，次要说明不低于 12。数字 tabular-nums，使用 Segoe UI / Microsoft YaHei 等系统字体，不下载网络字体。间距基于 4/8/12/16/24，主卡内距 20–24，辅助卡 16，圆角 8–12。

交互按钮目标至少 32 DIP，正常主操作约 40；有明确 focus-visible、禁用/忙碌状态，控件 label 不被 placeholder 替代。键盘 Tab 顺序、Enter 保存、Esc 返回/取消及原生 Alt+F4 按当前窗口语义处理，不注册全局快捷键。

## D10 实际组件与使用约束（2026-10-14）

代码与预览用法见 [desktop/preview/README](../../../desktop/preview/README.md)（仓库根目录`desktop/preview/README.md`）。tokens/base仅在`.workday-ui`作用域生效，字体使用系统Segoe UI/Microsoft YaHei，数值tabular-nums；间距4/8/12/16/20/24、圆角8/12、焦点3px、控件/复选标签32px。海蓝默认，珊瑚可选；controller操作单一host、不写配置，取消或卸载可恢复旧属性和移除监听。

- MetricCard：title/value/unit/description/source/estimated/warning/kind/emptyLabel。0为有效数值，null/空白/非有限数为无数据；估算提示贴近指标，salary永远说明仅计划日期，歧义由上层传null/提示，不自行选周期。
